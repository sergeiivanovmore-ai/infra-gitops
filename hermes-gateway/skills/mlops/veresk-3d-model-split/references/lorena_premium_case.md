# Кейс: Лорэна Премиум — 42 предмета из 1082 объектов

Модель длинного ряда корпусов. Показывает, что объединение по перекрытию габаритов
работает и там, где разбиение по зазорам ломается — но **требует визуальной
проверки широких блоков**.

## Профиль модели

| Параметр | Значение |
|----------|----------|
| Меш-объектов | 1082 |
| Полигонов | 490 274 |
| Габариты | X 61.10 × Y 1.71 × Z 2.62 |
| Actions в сцене | 890 |
| Главная ось | X (61.1 против 2.6 по Z — ряды в 23× длиннее) |
| Положительных зазоров | 266 |
| Крупнейший зазор | **0.7108 = 1.2 % длины** |

1.2 % — зазор технологический, а не стык модулей. Разрезание по зазорам здесь
не работает (как на Вильене: 0.7 % → `auto` дал 181 осколок).

## Что сработало: объединение по перекрытию

Интервалы `[x0, x1]` всех объектов, объединить перекрывающиеся:

```python
iv = sorted(((info[o]["x0"], info[o]["x1"], i, o) for i, o in enumerate(meshes)),
            key=lambda t: (t[0], t[1]))
merged = []
for a, b, _i, o in iv:
    if merged and a <= merged[-1][1] + 1e-9:
        merged[-1][1] = max(merged[-1][1], b); merged[-1][2].append(o)
    else:
        merged.append([a, b, [o]])
```

Результат: **43 кластера**, сумма объектов 1082 = исходному числу. Инвариант
сошёлся сразу — ни один объект не потерян и не задвоен.

## Что потребовало глаз: широкие блоки

Кластеры шириной 2.0 м (их 8 штук) выглядят как «два корпуса по 1 м».
Изометрия показала **единый шкаф на 4 двери**: слитный цоколь, общий цоколь,
фасады встык. Делить не надо.

Контрольный кадр — два соседних кластера по 2.0 м (60 объектов) изометрией:
слева один шкаф на 4 двери, справа другой шкаф с открытыми полками (видны
внутренние перегородки). Это два предмета, границы кластеров верны.

> **Правило:** ширина кластера > 1.8 м — кандидат на «внутри два шкафа».
> Проверять рендером, не решать по ширине. На Лорэне проверка дала «не делить».

## Осколок: 22 мм

Кластер №4 — один объект `Object1138`, ширина **0.022**, зазор до правого
соседа №5 — **0.0009** (фактически касание). Присоединён к №5.

Автоматическое правило в батче:

```python
for c in clusters:
    if c["n_obj"] <= 2 and c["w"] < 0.06:
        # ближайший сосед по расстоянию границ
        MERGE[c["n"]] = ближайший_сосед
```

Рендер подтвердил: осколок — накладка/стойка, самостоятельного предмета нет.

Дарио пришлось **дорезать** (исходно 211 кусков, пользователь указал 18 разделений
и 78 склеек). Лорэна Премиум сразу разложилась чисто — разная природа сцены:
у Дарио модули смыкались вплотную, у Лорэны между корпусами есть реальные
технологические зазоры 0.1-0.7 м.

**Вывод:** нельзя заранее выбирать стратегию. Сначала объединение по перекрытию
и проверка инварианта суммы объектов — если сходится и пустых нет, разбиение
вероятно корректно, и дальше нужна только точечная визуальная проверка широких
блоков и осколков.
