# Сколько на самом деле объектов в модели

Разбиение по зазорам отвечает на вопрос «на сколько полос режется», но не
на вопрос «это один массив или несколько отдельных предметов». Эти два ответа
могут разойтись, и пользователь сразу это видит на рендере.

---

## Независимая проверка: связные компоненты по пересечению AABB

Union-find по пересечению габаритов даёт **второе, независимое** мнение о числе
отдельных объектов. Если оно совпало с числом частей — разбиение подтверждено.

```python
parent = {o.name: o.name for o in meshes}
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]; x = parent[x]
    return x
def union(a, b):
    ra, rb = find(a), find(b)
    if ra != rb: parent[ra] = rb

for i in range(len(meshes)):
    for j in range(i + 1, len(meshes)):
        a, b = meshes[i], meshes[j]
        if all(a.max[k] > b.min[k] and b.max[k] > a.min[k] for k in range(3)):
            union(a.name, b.name)

comps = {}
for o in meshes:
    comps.setdefault(find(o.name), []).append(o)
sizes = sorted((len(v) for v in comps.values()), reverse=True)
```

На Penaly: `COMPONENTS 12, SIZES [21, 21, 17, 17, 16, 9, 4, 1, 1, 1, 1, 1]`.
Крупные кластеры **совпали** с четырьмя частями разбиения.

## Когда этот метод НЕ работает

На плотных модульных рядах он бесполезен — см. «Плотные модульные ряды»:
на Вильене union-find дал **472 группы, из них 381 одиночка**. Не выдавай это
за «готовые модули». Используй его **только как перекрёстную проверку числа**
на моделях с явными зазорами.

## Сверка с разбиением по зазорам

```python
# 1. каждый объект ровно в одной части
assert assigned == total_meshes
assert sum(part_objects) == total_meshes

# 2. зазоры между соседними частями положительны
#    (отрицательный зазор = части перекрываются по главной оси)
for i in range(len(bands) - 1):
    gap = bands[i + 1][0] - bands[i][1]
    print(f"{bands[i][2]}об -> {bands[i+1][2]}об : зазор={gap:.3f}")

# 3. имена из groups.json совпадают с импортом
missing = [n for n in all_grouped if n not in imported_names]
```

Кейс Penaly — 110 объектов, 4 части, сумма по частям 17+38+17+38 = 110,
зазоры **0.104 / 0.465 / 0.133** (все положительные), 0 имён без группы.
Разбиение корректно.

## Показывай пользователю числа, а не картинку

Расхождение мнений о числе объектов («я вижу 3») почти всегда разрешается
цифрами: X-полосы, зазоры, число объектов в каждой. Приводи их до того, как
предлагать переделывать:

```
17 об, X[-1.338, -0.838] — глухой шкаф
38 об, X[-0.734, -0.234] — шкаф с открытыми полками
17 об, X[ 0.231,  0.831] — глухой шкаф
38 об, X[ 0.964,  1.564] — шкаф с распахнутой дверью
зазоры: 0.104 / 0.465 / 0.133
```

## Полезный признак: зеркальная симметрия

Если части попарно совпадают по числу объектов и геометрии (17↔17, 38↔38) —
модель симметрична, и разбиение по главной оси корректно. Асимметрия при
равных размерах — повод проверить, не разрезан ли модуль пополам.
